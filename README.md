# 跨 ±180° 禁区航路 SVG 编辑台

纯 React + TypeScript 的离线编辑台：不请求任何在线地图瓦片，画面就是一张
等距圆柱经纬网 SVG。核心几何完全用 **整数方向判定（BigInt）+ 约分分数** 完成，
覆盖禁区跨越 ±180° 经线时的判定、区间计算与日界线两侧分段绘制。

## 运行

```bash
# 开发
npm install
npm run dev          # http://localhost:5173

# 测试
npm test

# Docker Compose（chart 页面，nginx 托管纯静态产物）
docker compose up --build      # http://localhost:8080
```

## 输入约定

- 坐标单位：整数 **百万分之一度**（microdegrees）。
- 禁区：3～20 顶点的凸多边形，纬度 ±80°，经度 ±540°。
- 航路：2～80 点折线。
- **相邻经度按短弧展开**：差值被平移 360° 的整数倍到 (−180°, 180°)；
  恰好相差 180° 的边歧义，直接拒绝。闭合边同样按短弧检查，跨度 ≥180° 的
  凸多边形（世界副本会重叠）拒绝。
- 非凸（连续叉积符号不一致）与自交（非相邻边整数方向判定）直接拒绝；
  允许边上的共线点，拒绝零长度边与零面积退化多边形。

## 判定方法（src/geometry/）

| 文件 | 职责 |
| --- | --- |
| `fraction.ts` | 约分分数（BigInt）、精确比较、`wrapLon` 卷绕到 [-180,180) |
| `unwrap.ts` | 短弧展开、坐标范围校验 |
| `zone.ts` | 凸性/自交整数判定，统一逆时针输出 |
| `intercept.ts` | 必要世界副本枚举 + 凸多边形半平面裁剪，求每段内部参数区间 |
| `display.ts` | 被截航路、禁区在日界线处的精确分段（画面与区间表同源） |
| `compress.ts` | 安全压缩：候选捷径边判定 + 最少航段/字典序最小求解 |

- 航段与禁区都按展开后的经纬平面直线解释；对每个航段只检查 bbox 相交所必要的
  世界副本 k（禁区平移 360°·k）。
- 半平面约束 `cross(edge, p(t)−v0) ≥ 0`（**边界计入**），`num + den·t` 的根
  是约分分数，区间裁剪全程无浮点。
- 每段命中区间先在段内（跨副本）合并，再按全局参数 `s = 段索引 + t` 合并相邻
  （端点相接即合并），每个合并区间列出**进入/离开见证**（段号、局部 t、
  展开坐标与归一化地理坐标）。

## 画面与区间表的一致性

`useDerivedGeometry` 是唯一数据通道：

```
原始点 → createZone/createRoute（短弧展开+校验）
       → analyzeRoute（世界副本+分数区间+见证）
       → buildRoutePieces/buildZonePieces（日界线分段）
       → SVG 画面与区间表
```

- 被截航路（金色加粗）只画 `segHits` 切出的分段；在 180° 处断开，
  分别落在窗口左右两侧。
- 禁区（红色虚线）经两次半平面裁剪（lon≤180、lon≥−180）成两片绘制。
- 图上进入 ▲ / 离开 ● 见证与区间表行双向高亮，二者指向同一条被截航路
  （有参数级一致性测试）。

## 安全压缩预演

画好绕开禁区的航路后，可点工具栏「安全压缩预演」删去多余航点：

- **只能从现有航点中保留包含首尾点的子序列**；每条新航段独立按现有
  短弧展开、必要世界副本与精确禁区裁剪规则检查。
- **触碰禁区边界同样不可用**（比区间表「边界计入」更严格：裁剪区间
  退化为单点也淘汰该边）；恰好 180° 的候选捷径只淘汰该边，不使工作区失效。
- 在所有安全方案中**先取航段数最少者，再取原航点下标序列字典序最小者**
  （候选边只从低下标指向高下标，按下标顺序做 DAG 动态规划即可取到双关键字最优）；
  无方案时明确报告，不交付部分航路。
- 预演线（绿色虚线）、保留下标与命中说明来自同一份 `CompressResult`；
  **确认前不改原航路**，确认后才用保留点替换；任何禁区/航点编辑立即撤销旧预演，
  原命中区间表保持原口径。

## 测试覆盖

`npm test`（74 个用例）：竖直跨区命中段（经度不变不再除零）、跨线非对称子区间
（参数 0.1/0.65，日界线两侧短片段）、贴线禁区无零面积幽灵片、SVG 不出现横跨整图
命中线、两侧经度等价表示（170/-170 与 170/190、+540° 边界）、顶点擦过（单点区间）、
沿边行走（边界计入）、跨线闭合环、恰好 180° 歧义边拒绝、非凸/自交拒绝、必要世界副本数、
日界线分段、画面段与区间见证同源；安全压缩另覆盖：短航路全子序列枚举核对最优性
（含确定性伪随机航路）、日界线两侧等价经度结果一致、边界擦触淘汰、180°/零长度
候选边只淘汰该边、不可行明确报告、结果同源性与输入不可变、React/SVG 渲染级贯通。
